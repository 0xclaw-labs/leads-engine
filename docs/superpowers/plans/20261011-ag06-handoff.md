## 切片 4：HUI-2391 BFF 路由（FEATURE_MATRIX_HANDOFF）

1. RED：`httpapi` 测试（httptest 假 AG10）：
   - 开关 off 时路由 404；
   - 开关 on、URL 缺失 → 503 `config_gate_matrix`；
   - 正常创建 → 201，本地行写入，`published=false`、`charged=false`、`plan/item/external=null`；
   - 同参重复 → 200 `idempotent_replay`，AG10 每次都被调用（服务决定重放），创建只发生一次；
   - 客户端传 `content_type=image` → 422 `wrong_type`；
   - 请求体含 phone/email → 400；
   - AG10 403 `grant_revoked` 透传 403，不写本地行；撤权后的重放同样 403，既有行不变；
   - AG10 不可达 → 503 `matrix_unavailable`，不写本地行；
   - 跨租户会话读取 → 404。
2. GREEN：`handlers_matrix_draft.go`，`config` 新增 `FEATURE_MATRIX_HANDOFF`、`MATRIX_DRAFT_BASE_URL`。

验证：`GOWORK=off go test ./internal/httpapi/ -run 'MatrixDraft' -count=1`
