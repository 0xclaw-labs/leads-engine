# AG06-AI 真实文本接入 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans（本轮无子代理派生工具，协调者在本会话内逐任务执行；每任务先红后绿）。Steps use checkbox syntax.

**Goal:** 让轻文案与接待 AI 回复通过正式 platform-task provider 获得真实文本候选，并在依据不足时安全降级。

**Architecture:** 复用现有 platformtask 客户端（三键配置）。轻文案生成写入独立回执表且不改草稿；接待回复仅在通过 FAQ 依据校验时替换正文。

**Tech Stack:** Go 1.26，SQLite（modernc），net/http httptest，既有 httpapi 测试夹具。

**Spec:** docs/superpowers/specs/20261011-ag06-ai-design.md

## Global Constraints

- 不改草稿表 CHECK（origin='manual'、generated=0、live_charge=0）。
- 不新增环境变量；provider 三键 PLATFORM_TASK_BASE_URL / TOKEN / ACCOUNT_ID。
- 费用单位 1 分；hold 0.01 元；billing_verdict 只能是 recorded 或 not_completed。
- 不发送、不发布、不记营销许可。
- fixture 不写成生产证据。

## Review Focus

1. 模型正文含未经事实的数字或价格 → 接待保留 FAQ；轻文案 409 model_ungrounded。
2. 访客文本或联系人全文进入 prompt → 测试断言 prompt 不含标记串。
3. 人工草稿非空时生成 → 不覆盖草稿，只返回候选。
4. 同内容重复点击 → 同一 idempotency key，不新增费用。
5. provider 超时或 UNKNOWN → verdict not_completed，不计费、不盲重提。
